# One Pager: Media Management

##  1.
Cooking and restaurant type games like Papa’s Pancakeria rely on visual, audio, and UI media to create the personality of their games. Their media usually focuses on helping the cooking aspect: sprite changes for food states, animations for actions like pouring and flipping, UI elements like timers and order meters, and short transition sequences that structure the flow of a restaurant day. Sound design plays an important part as well: sizzling audio gives a sense of heat, small chimes for perfect timing, and harsher cues warn the player when something is burning or an order is running low. Background art and looping music set the atmosphere and keep the scene from feeling empty. All of these media components work together to help the restaurant feel through sound and visuals.

## 2.
One practical strategy I’ve already been experimenting with is using media directly through Unity’s built in systems: sprite swaps, UI images, animators, and audio sources. This approach helps the most because it’s straightforward and direct enough for me as a beginner. The downside is that it doesn’t look polished, and a lot of the time something feels off with either the visuals or audio. A second, more polished approach would be using cinematic techniques: UI transitions, quick intro scenes, and small cutscenes. The challenge is that it’s more complex and potentially disruptive to gameplay flow. I want to balance my use of media so the game feels creative while staying realistic about my constraints.

## 3.
For my project, most of the gameplay should rely on Unity’s in engine media with a few animated UI sequences for transitions. The cooking loop benefits from direct media integration: crisp sprite changes for raw, cooked, and burnt; sound cues for flipping and sizzling; and a clean visual timing indicator to keep the system readable. These elements support the core mechanics without adding unnecessary work. I might add transitions for each day, like “Day Start” and “Day Complete.” I want to add features slowly and realistically. This part of development is where I’ll have the most fun, because cooking games only become satisfying when the visuals, sounds, and UI communicate tension and timing.
